# ВАЙБ КОД — сахарные скрабы для тела

Сайт-визитка бренда сахарных скрабов ВАЙБ КОД (THE V CODE).

## Что внутри

- `index.html`, `styles.css` — одностраничный сайт (лендинг)
- `images/` — логотип, главное фото, фото товаров
- `labels/` — этикетки скрабов (макадамия, кофе, цитрус)

## Запуск локально

Сайт статический — достаточно открыть `index.html` в браузере
или поднять любой статический сервер, например:

```bash
npx serve .
```
